# hack-615e4e31-cyber-shield
Hackathon team repository for Cyber​​Shield

## Статус проекта

Подготовлен план MVP для кейса AI Sana о качестве бизнес-задач и открытом выборе студенческих команд. Приложение пока не реализовано; команды его запуска появятся вместе с первым работающим каркасом.

Планируемый сценарий: описание потребности → уточняющие вопросы AI → редактируемая карточка → подтверждение и рейтинг → публикация в каталоге → отклик команды → ручное решение бизнеса.

## Документация

[План разработки](DEVELOPMENT_PLAN.md) содержит объём MVP, распределение задач между агентами, правила рейтинга, требования к AI, критерии оценки и проверки готовности.

Инструкция запуска будет включать проверенные версии инструментов, установку зависимостей, настройку окружения, подготовку базы и тестовых данных, запуск интерфейса и сервера, режим без AI-ключа и решение частых проблем. Перед сдачей запуск будет проверен в чистой копии проекта по README.

## Сохранение изменений

По запросу владельца в Codex настроено сохранение текущего прогресса в ветку `main` каждые 40 минут при наличии изменений. Это локальная автоматизация текущей задачи Codex; она не является GitHub Actions workflow и не разворачивает сайт. Для выполнения компьютер должен быть включён, а приложение Codex — запущено.

Промежуточные коммиты могут содержать незавершённую работу, состояние которой указывается в описании коммита. Секреты, локальные настройки, зависимости и сборочные артефакты в репозиторий не включаются.
