# Alem · интерфейс

React + TypeScript + Next.js. Полная инструкция по установке, совместному запуску Python API и проверке проекта находится в [README корня](../README.md).

`npm run dev` запускает интерфейс на http://127.0.0.1:5173. API должен работать на http://127.0.0.1:8000. Запросы `/api/*` проксируются через `next.config.ts`.
