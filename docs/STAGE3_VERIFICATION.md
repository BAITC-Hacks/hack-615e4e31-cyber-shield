# Проверка баллов команд и семантического рейтинга

Дата: **23 сентября 2026 года**. Окружение: macOS, Python 3.13.9, Node.js 25.8.0, Next.js 16.3.4. Приложение собрано и запущено локально в production-режиме на портах 5173 и 8000. Предыдущие проверки откликов и PDF сохранены в [STAGE2_VERIFICATION.md](STAGE2_VERIFICATION.md).

## Автоматические проверки

- `backend/.venv/bin/python -m pytest backend/tests -q` — **230 passed, 1 warning**, 8,94 с.
- `backend/.venv/bin/python -m pip check` — ошибок зависимостей нет.
- `python3 scripts/setup.py --check` — успешно.
- `npm --prefix frontend run typecheck`, `npm --prefix frontend run lint`, `npm --prefix frontend run build` — успешно.

Единственное предупреждение — известная смена HTTP-клиента в будущей версии Starlette TestClient. Все backend-тесты работают с временными базами, `.env` отключён; внешние AI-вызовы имитируются. Реальный API и доступ пользователя к модели этим прогоном не проверены.

Новые тесты покрывают:

- Награду только за ручное завершение выбранного проекта, однократность по команде и задаче, запрет изменения решения после завершения.
- Атомарность завершения и журнала, конкурентные начисления/покупки, невозможность отрицательного баланса, повторные запросы без двойного списания.
- Владение оформлением, соответствие слоту, бесплатное снятие/применение и сохранность после открытия базы заново.
- Строгий запрос Responses API, проверку восьми ответов и буквальных цитат, отказ при выдуманном источнике, неверном JSON, тайм-ауте и ошибке провайдера.
- Уменьшение оценки с локальных 100 до 85 при отказе AI по критериям успеха; использование этой оценки при подтверждении и публикации.
- Запрет публикации старого локального подтверждения после подключения AI; сохранность прежней публикации при ошибке; конфликт изменения карточки во время сетевой проверки.
- Ответы из 1–3 букв дают ноль по каждому из девяти оцениваемых полей. Исходные синтетические рейтинги 20/50/75/90/100 сохранены.
- Кэш успешных ответов и его инвалидирование при смене полей, модели, версии или ключа; отсутствие секрета в ответах; приоритет окружения над `.env`.

## Проверка в браузере

1. Использован ранее созданный демонстрационный отклик Simple Flow на пекарню с 20 баллами. В роли бизнеса открыт диалог завершения: без описания и отметки ручной проверки подтверждение недоступно.
2. Введено описание именно демонстрационной проверки, поставлена отметка. После подтверждения появились «Проект завершён» и **+100 баллов**; изменение решения стало недоступно. Исходный отклик Qadam Web остался на рассмотрении.
3. В роли студента выбрана Simple Flow в разделе «Комната и награды». Баланс — **100**, заработано — **100**, завершён **1** проект.
4. Куплена Монстера за **40** и применена в комнате. Затем куплен фон «Утреннее небо» за **60** и применён. Итог: баланс **0**, заработано **100**, коллекция **2/6**. История содержит +100, −40, −60; неподъёмные покупки заблокированы.
5. Страница обновлена, роль и команда выбраны заново. Баланс, растение, фон и история сохранились. Комната просмотрена при ширине 1280 и 390 пикселей; горизонтального переполнения нет, фон и предметы видны. Временное изменение размера браузера сброшено.
6. В новом редакторе показано «AI пока не подключён» и неактивная кнопка внешней проверки. В контекст и потребность введены `аб` и `вг`: предварительная оценка **0**, у обоих полей есть пояснения. Тестовый текст не сохранён.
7. Ошибок в консоли приложения при этих действиях не обнаружено.

В локальной базе оставлено только явно обозначенное демонстрационное завершение и покупки Simple Flow. Они помогают показать комнату пользователю, но не входят в стартовые данные нового клона и не включаются в Git. На новой базе все команды начинают с нулём.

## Что ещё зависит от окружения

Пользователю нужно вставить ключ в `.env` и перезапустить backend. Проверить реальный ответ можно кнопкой редактора или `backend/.venv/bin/python scripts/check_ai.py --request`. Пока ключ не задан, нельзя утверждать, что модель действительно оценила текст; интерфейс прямо показывает локальный режим.

Модель может ошибаться в смысле и не доказывает истинность фактов. Подтверждение бизнеса остаётся обязательным. Роли и принадлежность к командам пока демонстрационные; обмена на реальные подписки нет. Эти границы также описаны в [REWARDS.md](REWARDS.md) и [SEMANTIC_RATING.md](SEMANTIC_RATING.md).
