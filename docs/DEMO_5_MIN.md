Видео включено в репозиторий без перекодирования и доступно после клонирования или скачивания исходников. Если GitHub не показывает проигрыватель, скачайте файл и откройте локально.

## Подготовка до начала показа

- Запустите приложение по [QUICKSTART.md](QUICKSTART.md) и откройте роль «Бизнесмен». Оставьте редактор новой задачи готовым к первому вводу.
- Откройте этот документ рядом, чтобы копировать подготовленные значения. Не перезаписывайте и не удаляйте рабочую базу ради демонстрации.
- При подключённом API проверьте доступность модели заранее. Без ключа покажите явно обозначенный локальный режим. Настройки и отдельная демонстрационная база описаны в [RUNBOOK.md](RUNBOOK.md).
- Включение записи экрана выполняет пользователь. Начинайте отсчёт после подготовки окна, перед первым вводом. Полученный видеофайл нужно отдельно проверить на изображение, звук и длительность.

Локальная формула `rules-v2` проверена на этих текстах: **20 → 70 → 100**. Это предварительные оценки формы. Сохранённый неподтверждённый черновик имеет **0** баллов. При внешнем AI итог может отличаться: показывайте фактический результат и его объяснение, не обещайте заранее 100 баллов.
