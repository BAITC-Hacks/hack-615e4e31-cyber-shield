# Простая инструкция запуска Alem

Эта инструкция помогает открыть MVP и попробовать его без настройки AI. Более подробные пояснения, отдельный запуск сервисов, AI и устранение ошибок — в [подробном руководстве](RUNBOOK.md).

## 1. Подготовьте компьютер

Нужны **Python 3.11 или новее**, **Node.js 22.13.0 или новее с npm** и Git для скачивания командой ниже. Общая команда запуска рассчитана на macOS/Linux; проверка выполнена на macOS. Windows этим способом не поддерживается.

Откройте терминал и проверьте, что программы доступны:

```sh
python3 --version
node --version
npm --version
git --version
```

Если терминал сообщает «command not found», сначала установите соответствующую программу. Без Git можно скачать ZIP через **Code → Download ZIP** на [странице репозитория](https://github.com/BAITC-Hacks/hack-615e4e31-cyber-shield), распаковать его и открыть терминал в распакованной папке.

## 2. Скачайте проект

В терминале перейдите в папку, где хотите хранить проект, и выполните:

```sh
git clone https://github.com/BAITC-Hacks/hack-615e4e31-cyber-shield.git Hakaton
cd Hakaton
```

Если проект уже скачан или вы используете ZIP, повторять клонирование не нужно: откройте его корневую папку, где находятся `README.md`, `backend`, `frontend` и `scripts`.

## 3. Установите и запустите

По очереди выполните две команды из корня проекта:

```sh
python3 scripts/setup.py
python3 scripts/dev.py
```

Первая команда устанавливает зависимости; дождитесь её завершения. При первой установке нужен интернет. Вторая запускает приложение — оставьте этот терминал открытым. Дождитесь сообщения **Ready**, затем откройте **[http://127.0.0.1:5173](http://127.0.0.1:5173)**.

Ключ API для запуска не нужен. В чистой копии без ключа AI-помощник честно показывает резервный режим. Подключить настоящую модель можно позже по [подробной инструкции](RUNBOOK.md).

## 4. Попробуйте приложение

1. В роли **«Бизнесмен»** нажмите **«Создать задачу»**, заполните название и описание. На последнем шаге подтвердите сведения и нажмите **«Опубликовать задачу»**. Если пока хотите продолжить позже, используйте **«Сохранить черновик»** — студентам он ещё не виден.
2. Переключитесь на **«Студент»**, найдите опубликованную задачу и отправьте отклик от тестовой команды: идею, план, срок и ссылку на прототип. Для пробы можно указать демонстрационную ссылку `https://example.com/orders-demo`; настоящий прототип по ней не размещён. При желании приложите PDF из `fixtures/proposal_demo.pdf`.
3. Вернитесь в роль бизнеса, откройте **«Отклики команд»** и вручную выберите или отклоните предложение.

Регистрация не нужна: в MVP две тестовые роли. На новой базе уже есть пять опубликованных задач, пять черновиков, команды и отклики. Число задач может быть больше, если приложение запускалось раньше. Формула рейтинга и подробные сценарии находятся в [README](../README.md).

## 5. Остановите или запустите снова

Для остановки нажмите **Ctrl+C** в терминале с приложением. Для следующего запуска откройте корень проекта и выполните только:

```sh
python3 scripts/dev.py
```

Данные сохраняются между запусками. Если терминал сообщает, что порты заняты, возможно, приложение уже работает: откройте страницу или остановите свой предыдущий запуск через Ctrl+C. Другие причины и способы проверки описаны в [RUNBOOK.md](RUNBOOK.md).
