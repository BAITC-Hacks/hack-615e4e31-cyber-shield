# Проверка откликов, PDF и качества описания

Дата: **23 сентября 2026 года**. Этот отчёт дополняет исторический [отчёт первой части](PART1_VERIFICATION.md). Команды запуска и воспроизводимые сценарии находятся в [README](../README.md).

## Соответствие обязательным модулям

| Требование | Реализация и способ проверки |
| --- | --- |
| Конструктор задачи | Свободный ввод, AI-проверка полноты и уточняющие вопросы, редактируемый результат с источниками; публикация только после ручного подтверждения. Контракт и резервный режим: [AI.md](AI.md), тесты `test_ai.py`. |
| Карточка задачи | Название, контекст, потребность, пользователи, данные, ограничения, результат, критерии успеха, контакт и взаимодействие доступны в редакторе и просмотре. |
| Рейтинг 0–100 | Прежние веса и уровни сохранены. Баллы требуют содержательного заполнения и подтверждения; есть расшифровка и подсказки. Изменение черновика не меняет опубликованную версию. Проверки: `test_quality.py`, `test_part1_api.py`, `test_workflow.py`. |
| Общий каталог | Все опубликованные задачи доступны всем тестовым командам; рейтинг определяет порядок. Фильтры по направлению и готовности. Низкий рейтинг не запрещает отклик. |
| Отклики команд | Явный выбор команды, идея, пошаговый план, срок, ссылка на прототип, необязательные допущения и PDF. Количество откликов не ограничено, включая повторные предложения команды на ту же задачу. |
| Ручной выбор бизнеса | Сравнение предложений, выбор, отклонение и возврат на рассмотрение; комментарий виден команде. Можно выбрать несколько предложений. Автоматического назначения нет. |

Таблица показывает реализованные возможности, а не гарантирует оценку жюри. Сохранение квеста не отправляет предложение и не назначает исполнителя.

## Автоматические проверки

Проверенное окружение: macOS, Python 3.13.9, Node.js 25.8.0. Production-сборка Next.js 16.3.4 запущена через `python3 scripts/dev.py --production` на локальных портах 5173 и 8000.

| Проверка | Результат |
| --- | --- |
| `backend/.venv/bin/python -m pytest backend/tests -q` | **132 passed, 1 warning**, 5,68 секунды |
| `backend/.venv/bin/python -m pip check` | Ошибок зависимостей нет |
| `python3 scripts/setup.py --check` | Успешно |
| `npm --prefix frontend run typecheck` | Успешно |
| `npm --prefix frontend run lint` | Успешно |
| `npm --prefix frontend run build` | Production-сборка успешна |

Предупреждение относится к будущей смене HTTP-клиента в Starlette TestClient. AI-тесты используют `httpx.MockTransport`: реальная внешняя модель в этом прогоне не вызывалась. Backend-тесты работают с отдельными временными базами.

Проверки покрывают роли, валидацию предложений и ссылок, неограниченные повторные отклики, отсутствие автоматического выбора, независимые решения бизнеса, миграцию исходных данных без дублирования, сохранность после повторного открытия базы и пересчёт рейтинга без публикации частного черновика. PDF-тесты дополнительно проверяют ограничения размера, имён и формата, атомарность записи, права скачивания и отсутствие файла при отказе.

## Проверка в браузере

В production-приложении выполнен следующий путь:

1. В роли студента открыта опубликованная задача пекарни с **20 баллами**. Выбрана команда Simple Flow, заполнены идея, три шага плана, срок 7 дней, демонстрационная ссылка и допущение о синтетических данных.
2. Через файловый диалог прикреплён [proposal_demo.pdf](../fixtures/proposal_demo.pdf), 876 байт. После отправки интерфейс показал «На рассмотрении» и подтверждение загрузки PDF.
3. В режиме бизнеса новый отклик появился рядом с исходным предложением Qadam Web. PDF скачан через кнопку. SHA256 скачанного файла совпал с исходным: `bb9552b0e22651e8a74eac05964d602d06209ffae3d65c32023a15040c0be8cf`.
4. Бизнес вручную выбрал новый отклик с демонстрационным комментарием. В разделе «Мои отклики» у Simple Flow появились статус «Команда выбрана», комментарий и PDF; исходное предложение этой команды на доставку осталось на рассмотрении.
5. В редакторе пекарни фраза «Всё должно работать хорошо» не дала баллов за критерии и вызвала конкретную подсказку. Замена на «100 строк импортируются без потерь; фильтр отвечает до 1 секунды» дала **15 баллов**, предварительная оценка изменилась с **20 до 35**.
6. Выход из изменённой формы показал предупреждение о несохранённом вводе. Выбран выход без сохранения; в каталоге сохранились исходные **20 баллов**.
7. Просмотрены каталог на экране 1280 пикселей и карточка отклика при 390 × 844. Горизонтального переполнения нет; кнопки, план и ссылка помещаются. Временный размер экрана сброшен. Ошибок в консоли приложения не обнаружено.

Демонстрационный отклик с маленьким PDF оставлен в локальной базе для просмотра. Он помечен текстом «Демо-проверка». База и скачанные файлы не включаются в Git; исходные записи набора не изменены.

## Проверка размера через Next.js

Проверка HTTP выполнялась через `http://127.0.0.1:5173`, то есть через тот же прокси, что использует браузер. Она проверяет транспортный лимит, а не корректность визуального содержимого большого PDF.

| Вход | Ожидаемый и полученный результат |
| --- | --- |
| PDF 10 485 760 байт; весь multipart 10 486 367 байт | **201**, отклик и вложение сохранены |
| Скачивание бизнесом и отправившей командой | **200**, оба файла по 10 485 760 байт; SHA256 совпадает с отправленным |
| PDF 10 485 761 байт | **413**, записи не созданы |
| Запрос multipart 11 010 650 байт | **413**, записи не созданы |

Проверены заголовки `Content-Disposition: attachment`, `X-Content-Type-Options: nosniff` и `Cache-Control: private, no-store`. Большое тестовое вложение и только его отклик удалены после проверки; существующие данные сохранены.

## Границы реализации

- Роли и пять команд остаются тестовыми: `X-Demo-Role` не заменяет авторизацию и проверку членства в команде. Приложение запускается локально; публичное размещение в этот этап не входило.
- Проверка качества объяснимая и основана на правилах, преимущественно для русского текста. Она находит типовые расплывчатые формулировки и признаки измеримости, но не доказывает истинность сведений и не гарантирует понимание любого текста. Окончательную проверку и подтверждение делает бизнес. Подробности: [QUALITY.md](QUALITY.md).
- В одном отклике поддерживается один PDF до 10 МиБ. Проверка сигнатуры и завершения PDF не является антивирусом. Содержимое вложения не отправляется в AI. Подробности: [PROPOSALS.md](PROPOSALS.md).
- Работа реального внешнего AI требует отдельной проверки с ключом. Локальный резервный режим обозначен в интерфейсе, промпты, вход/выход и обработка ошибок документированы.
- Автоматическая проверка существования прототипа, регистрация реальных команд и уведомления вне приложения не добавлялись.
